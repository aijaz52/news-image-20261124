# news-image-20261124

One image that sums up 24 November 2026's world news, rendered from a curated
HTML page (`news.html`) into `entry.png` by `main.ts`.

- Run: `node main.ts` (renders `news.html` to `entry.png` via Playwright)
- Output: `entry.png` (1280×720 summary image)
